# 0021. Report unused files and exports with knip

- Date: 2026-10-22
- Status: Accepted

## Context

On 2026-10-21, [#356](https://github.com/AIssoufi/issoufi.fr/pull/356) removed a page that no route rendered, its translations and an unused barrel. They had stayed in the repository for days, with their own tests, since nothing in the CI looks at the code as a whole: ESLint reads one file at a time, and TypeScript reports an unused local, never an export that no module imports nor a file that no entry point reaches.

On `develop` at `3e91798`, `npx knip@6.41.0` with no config reports 26 findings:

- 3 unused files, all used: the test and the config of the visual tests, which `pnpm test:visual` runs from a script, and the commitlint config of the pull request titles, which a workflow passes with `--config`;
- 1 unused dev dependency, wrangler, which the deploy job runs through `cloudflare/wrangler-action`;
- 17 unused exports: 3 that the visual test imports, 2 in `scripts/cv/`, and 12 constants that only their own file reads;
- 5 unused exported types: 4 that an exported type names, and `AppIconRole`, which nothing uses.

## Decision

In the pull request of [#357](https://github.com/AIssoufi/issoufi.fr/issues/357), knip 6.41.0 becomes a dev dependency, run by `pnpm knip` after ESLint in the `lint` job of the CI, even when ESLint failed. 6.42.0 and 6.42.1 were younger than the 7 days of `minimumReleaseAge`.

Its plugins find most entry points: `index.html` and the configs for Vite, the specs for Vitest, the tests for Playwright, the scripts of `package.json` and the `run` steps of the workflows. `knip.jsonc` adds the rest, each with its reason:

- the commitlint config of the pull request titles as an entry, and the visual Playwright config next to the main one;
- wrangler among the dependencies used;
- the exported types that their own file uses, such as those that an exported type names, which their users may need to name;
- the exports of `scripts/cv/constants.mjs` and `scripts/cv/utils/constants.mjs`, until [#370](https://github.com/AIssoufi/issoufi.fr/issues/370), since a pull request still open changes `scripts/cv/`.

The 12 constants lose their `export`, and `AppIconRole` goes.

## Alternatives considered

- **ts-prune**: reports unused exports only, and had no release since 2022-05-22.
- **ts-unused-exports**: reports unused exports, and files with an option, but no dependency; no release since 2024-11-25.
- **The `no-unused-modules` rule of eslint-plugin-import**: its 2.32.0 accepts ESLint up to 9, and the project runs ESLint 10.
- **A job of its own**: the `lint` job spends most of its time installing the dependencies, which a second job would install again.
- **`ignoreExportsUsedInFile` for every export**: it would also accept a constant exported for nothing, which only hides it from a reader.

## Consequences

Measured with Node.js 24.22.0, base and branch in turn, medians of three runs: the clean install with `node_modules` deleted and the store of pnpm warm, and knip 6.41.0 from the same install on both sides, with no config on the base. In the CI, the duration of the `lint` job on the last five runs of `develop` before the change.

| Figure                    | Before (`3e91798`) | After               |
| ------------------------- | ------------------ | ------------------- |
| knip findings             | 26                 | 0                   |
| knip run, local           | 0.57 s             | 0.57 s              |
| `lint` job in CI, median  | 24 s               | in the pull request |
| Clean install             | 0.5 s              | 0.5 s               |
| Direct dependencies (dev) | 36 (29)            | 37 (30)             |
| `pnpm audit` advisories   | 0                  | 0                   |

- A file that no entry point imports fails the `lint` job, as a throwaway commit of the pull request showed.
- An entry point that knip cannot find, such as a file that a script passes to a tool by its path, needs its line in `knip.jsonc`, or knip reports it as unused.
