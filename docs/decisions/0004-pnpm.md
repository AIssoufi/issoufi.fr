# 0004. Install the dependencies with pnpm

- Date: 2026-03-21
- Status: Accepted

## Context

The project installed its dependencies with npm and its `package-lock.json` since its first commit. npm copies every package into the `node_modules` of each checkout, and lets the code import a package that only a dependency declares, since it hoists them all to the top of `node_modules`.

## Decision

Commit `6e3054c`, pushed to the default branch with no pull request, on 2026-03-21, five minutes after the move to Vite ([0003](0003-vite-and-vitest.md)): `pnpm-lock.yaml` replaces `package-lock.json`.

- pnpm links each package from one store on the machine, so every checkout and worktree of the project shares the same files.
- A package sees only the dependencies that it declares, so an import of an undeclared package fails.
- On 2026-10-17, [#30](https://github.com/AIssoufi/issoufi.fr/pull/30) pins pnpm 10.34.7 with the `packageManager` field, the version that Cloudflare already used to build the site.

## Alternatives considered

The commit records no alternative. The ones open then:

- **Keep npm**: the copies per checkout and the access to undeclared packages stay.
- **Yarn**: its Plug'n'Play mode is strict too, but needs editor and tool support for a project without `node_modules`; its `node_modules` mode hoists like npm.

## Consequences

Measured on 2026-10-20 in a detached worktree of each commit, with Node.js 22.14.0, npm 10.9.2 and pnpm 10.34.7. Each install is the median of three runs after deleting `node_modules`: with an empty cache (`npm ci --cache <empty folder>`, `pnpm install --frozen-lockfile --store-dir <empty folder>`), then with the cache of the machine.

| Figure                   | Before (`47379f5`, npm) | After (`6e3054c`, pnpm) |
| ------------------------ | ----------------------- | ----------------------- |
| Install, empty cache     | 3.06 s                  | 2.19 s                  |
| Install, warm cache      | 1.69 s                  | 0.59 s                  |
| Build time (`run build`) | 2.34 s                  | 2.63 s                  |
| JavaScript and CSS, gzip | 178.2 kB                | 178.2 kB                |

- The build gives files of the same sizes: 175.1 kB of JavaScript and 3.1 kB of CSS gzipped. The build time moves within the spread of its three runs (2.29 to 3.02 s with npm, 2.41 to 3.74 s with pnpm).
- `npm audit` and `pnpm audit` count the advisories in different ways, so this record compares none: [Evolution](../evolution.md) gives the count of each era with its tool.
