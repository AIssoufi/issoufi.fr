issoufi.fr - version autonome / standalone version

FRANÇAIS

Ouvrez index.html dans votre navigateur, d'un double-clic : le site s'affiche sans serveur ni
installation, toutes ses pages et le choix de la langue compris. Il s'ouvre en français : la
langue se choisit avec le sélecteur FR / EN. Gardez les fichiers de ce dossier ensemble :
index.html y lit les images et le CV.

Les polices viennent de Google Fonts : hors connexion, le navigateur affiche les siennes.

Le site en ligne : https://issoufi.fr

ENGLISH

Open index.html in your browser with a double click: the site runs without a server or anything
to install, every page and the language toggle included. It opens in French: choose the language
with the FR / EN toggle. Keep the files of this folder together: index.html reads the images and
the CV from it.

The fonts come from Google Fonts: offline, the browser shows its own instead.

The website: https://issoufi.fr
